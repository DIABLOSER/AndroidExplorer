## 🎉 v3.3 更新

### 界面（VS Code 暗色风格）

- 默认 **Dark** 主题，三栏布局（资源列表 | 映射编辑 | 命名格式）
- 简约分隔线，面板标题与背景融合
- **映射编辑区** 左侧行号栏，与内容同步滚动
- **命名格式区** 可滚动，内容较多时自动显示滚动条（含随机数配置）
- 映射/日志区使用细窄 ttk 滚动条，按需显示

### 命名格式

- 固定四段：**前缀、关键词、后缀**（默认 `{random}`）、**序号**（默认 `{number:04d}`）
- **固定顺序** / **随机顺序**：可调整或随机打乱四段拼接顺序（序号不会放在首位）
- **随机字符配置**始终显示，用于展开后缀等处的 `{random}`
- 占位符：`{name}`、`{number:04d}`、`{random}`

### 类名处理

- **过滤字符**：逗号分隔的子串列表（如 `Activity,Fragment`）
- **替换字符**：将上述过滤项替换为的内容（与过滤一一对应；只填一项则全部共用；留空则删除）
- 处理顺序：过滤/替换 → 命名格式（未填过滤时仍可用 `源->目标` 规则）

### 性能与可靠性

- 类名引用更新：限定名与简单类名分步替换，覆盖 `Class.member`、`new Outer.Inner()` 等场景
- 批量引用替换：needle 预检、单次遍历项目文件
- 格式预览 **200ms 防抖**，减少输入卡顿

### 未使用资源清理（资源 / 布局 / 字符）

- **检测使用情况**：扫描项目内 Java/Kotlin/XML/Gradle 等引用
- 列表标注 `[未使用]`（橙色），底部显示统计
- **删除未使用**：确认后一键删除（Drawable/Layout 删文件，String 从 `strings.xml` 移除条目）
- 删除后自动重新扫描；反射、仅注释中的引用可能误判，删除前请备份

## 使用方法

### 运行

```bash
python app.py
```

### 打包（Windows）

```bash
pyinstaller "Android Explorer.spec"
```

输出位于 `dist/Android Explorer.exe`。

### 基本流程

1. **选择项目**：顶部菜单「文件」→ 选择 Android 项目根目录
2. **选择模块**：多模块项目可在顶部下拉框选择模块或「全部模块」
3. **切换资源类型**：左侧「资源 / 布局 / 字符 / ID / 类名」
4. **配置命名格式**：右侧面板设置部件、顺序模式、可选序号/随机数
5. **（可选）检测未使用资源**：在「资源 / 布局 / 字符」列表上方点击「检测使用情况」，再「删除未使用」
6. **生成映射**：菜单「生成映射」，在中间映射区查看（`旧名称 = 新名称`）
7. **编辑映射**：可直接编辑映射文本，「应用修改」保存
8. **执行**：菜单「执行」，确认后开始重命名

### 菜单与选项

| 菜单项     | 说明                         |
|-----------|------------------------------|
| 生成映射   | 按当前格式生成映射表           |
| 应用修改   | 保存中间区编辑后的映射         |
| 重置       | 恢复为上次生成的映射           |
| 清空       | 清空当前类型映射               |
| 导入/导出映射 | 团队协作、备份              |
| 反向映射   | 交换键值，用于还原             |
| 执行       | 执行重命名（受「预览」影响）   |

顶部选项：

- **预览**：不实际写文件，仅日志预览
- **更新引用**：同步更新 XML / Java / Kotlin / Gradle 等引用
- **子目录**：扫描与替换时包含子目录

## 功能特性

### 支持的资源类型

| 类型      | 说明                                      |
|----------|-------------------------------------------|
| Drawable | 图片等资源文件                             |
| Layout   | 布局 XML                                  |
| String   | `strings.xml` 中的 name                  |
| ID       | 布局中的 `@+id/xxx`                       |
| 类名      | `.java` / `.kt`，含 Manifest、import 等 |

### 命名格式详解

**四段部件**（顺序可调）：

- **前缀**、**关键词**、**后缀**（默认 `{random}`）、**序号**（默认 `{number:04d}`）
- 下方 **随机字符配置** 控制 `{random}` 展开结果（长度、字符集）

**顺序模式**：

- **固定顺序**：按列表从上到下的顺序拼接
- **随机顺序**：每条生成的名称独立随机打乱部件顺序

**占位符**：

| 占位符           | 含义           |
|-----------------|----------------|
| `{name}`        | 原资源名/类名  |
| `{number:04d}`  | 序号（可改格式）|
| `{random}`      | 随机字符串     |

**随机字符配置**（勾选「随机数」后显示）：

- 长度 1–20
- 可选：小写字母、大写字母、数字

**示例**（固定顺序：前缀 + 关键词 + 序号，前缀 `icon`，关键词 `{name}`，序号 `{number:04d}`）：

```
home → iconhome0001
```

若需要下划线分隔，请自行在前缀/关键词模板中写入（如 `icon` + `{name}` 可改为 `icon_` + `{name}_`）。

### 类名专用

1. **过滤字符**：`Activity,Fragment`  
2. **替换字符**：`View,Item` → `MainActivity` 变为 `MainView`，`ListFragment` 变为 `ListItem`  
3. **替换留空**：删除过滤子串；**替换只填一项**（如 `View`）则所有过滤项都替换为 `View`  
4. 再按命名格式生成新类名并更新引用

### 引用更新范围

- **Drawable**：`R.drawable.*`、`@drawable/*`
- **Layout**：`R.layout.*`、`@layout/*`、ViewBinding 等
- **String**：`R.string.*`、`@string/*`、`<string name="...">`
- **ID**：`R.id.*`、`@+id/*`、`@id/*`
- **Class**：import、声明、构造、`new`、静态调用、泛型、类型转换、for-each、Manifest、布局自定义 View 等（详见 v3.2.1 规则集）

排除目录示例：`build/`、`.gradle/`、`.git/`、`node_modules/` 等。

## 注意事项

1. 操作前请 **备份** 或使用 Git，预览模式也不能完全代替版本管理  
2. 多模块项目建议先选单一模块验证  
3. 执行前检查映射，避免命名冲突  
4. 类重命名后请 **编译运行** 验证；关注验证报告中的遗漏项  
5. 反射、字符串字面量中的类名、注释等可能不会自动更新

## 常见问题

### Q: 类重命名后编译报「找不到符号」？

1. 确认已勾选 **更新引用**  
2. 查看日志中的 **验证报告**（未更新文件与行号）  
3. 在项目内搜索旧类名手动修补遗漏  
4. 使用 **反向映射** + 再次执行可尝试回滚（建议优先用 Git）

### Q: 看不到「随机数模板」或「随机字符配置」？

1. 在右侧勾选 **随机数**  
2. 若面板较高内容被挡住，在命名格式区域 **向下滚动**  
3. 展开后列表会自动刷新滚动范围  

### Q: 如何回滚？

- **Git**：`git checkout .`  
- **工具**：导入原映射 → **反向映射** → 勾选更新引用 → **执行**

### Q: 支持哪些文件？

- `.java`、`.kt`、`.xml`、`.gradle` 等  
- 扫描时会跳过 `build`、`.idea` 等常见目录
